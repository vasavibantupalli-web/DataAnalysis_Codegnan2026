# 📊 Adult Census Income – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the **Adult Census Income Dataset**.

The main objective of this project is to understand the dataset, clean the data, identify patterns, analyze relationships between different features, and visualize important insights related to income and demographic information.

---

## 🎯 Objectives

* Understand the structure of the dataset
* Identify and handle missing/null values
* Check and remove duplicate records
* Perform data cleaning and preprocessing
* Detect and handle outliers
* Perform Exploratory Data Analysis
* Analyze relationships between different variables
* Create meaningful data visualizations
* Extract useful insights from the dataset

---

## 📂 Dataset

The dataset contains information about individuals based on demographic and employment-related attributes.

### Important Features

| Feature        | Description                           |
| -------------- | ------------------------------------- |
| Age            | Age of the individual                 |
| Workclass      | Type of employment                    |
| Final Weight   | Census sampling weight                |
| Education      | Education level                       |
| EducationNum   | Numerical representation of education |
| Marital Status | Marital status                        |
| Occupation     | Type of occupation                    |
| Relationship   | Relationship status                   |
| Race           | Race category                         |
| Sex            | Gender                                |
| Capital Gain   | Capital gain                          |
| Capital Loss   | Capital loss                          |
| Hours per Week | Working hours per week                |
| Native Country | Country of origin                     |
| Income         | Income category                       |

## 🔍 Data Analysis Process

### 1. Data Understanding

* Loaded the dataset
* Checked the number of rows and columns
* Examined column names and data types
* Generated descriptive statistics

### 2. Data Cleaning

The following data-cleaning techniques were performed:

* Identified missing/null values
* Handled missing values
* Checked duplicate records
* Removed unnecessary records/columns where required
* Checked inconsistent values
* Identified potential outliers

### 3. Exploratory Data Analysis

Different features were analyzed to understand:

* Age distribution
* Education levels
* Workclass distribution
* Working hours
* Income distribution
* Relationship between education and income
